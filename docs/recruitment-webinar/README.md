# 採用内製化 ウェビナー要点まとめ（PPTX）

採用戦略ウェビナーの要点を、採用担当がそのまま実務に使える形で 10 ページにまとめた資料です。

## 成果物

| ファイル | 内容 |
|---|---|
| `採用内製化_要点まとめ.pptx` | 本体（16:9 / 10 ページ / 日本語） |
| `build_deck.js` | 上記 PPTX を生成する pptxgenjs スクリプト |

## 構成（全 10 ページ）

| # | ページ | ねらい |
|---|---|---|
| 1 | タイトル | 4 つの約束（コスト 1/2 以下・欲しい人材・タイミング・内製化）を提示 |
| 2 | いまの採用、なぜうまくいかない？ | 3 つの痛み（お金・ミスマッチ・タイミング）で共感をつくる |
| 3 | たどり着く 4 つの状態 | ゴール像を先に見せる |
| 4 | なぜ高い？ お金の流れ | 採用単価の比較グラフ＋「変動費 → 固定費」の構造転換 |
| 5 | 「募集」から「集客」へ | Before / After で発想の転換を示す |
| 6 | 内製化する 5 ステップ | 全体プロセス図 |
| 7 | STEP 1-2：誰を、どこで探すか | MUST/WANT/NG シート＋チャネル比較表 |
| 8 | STEP 3-4：刺さる文面 × 速い選考 | スカウト文の Before/After＋スピード基準 |
| 9 | STEP 5：数字で回す | 採用ファネルと毎週見る 3 つの「率」 |
| 10 | 明日から動く 30 日プラン | 週ごとのアクションリスト |

## デザイン方針

- 14 歳が読んでも分かる語彙・文長に統一（専門用語は初出で言い換え）
- 全ページに図・アイコン・カード・グラフのいずれかを配置（文字だけのページなし）
- ネイビー基調＋オレンジのアクセント 1 色。表紙と最終ページのみダーク背景
- 各ページにスピーカーノート付き

## 数字の出典について

金額・比率は一般的な相場からの **試算例** です（人材紹介の成功報酬は理論年収の 30〜35%
が相場、という業界一般の水準を基準にしています）。実データに差し替える場合は
`build_deck.js` 内のスライド 4 の `values` と、スライド 2 の本文を編集してください。

## 再生成の手順

```bash
npm install pptxgenjs react react-dom react-icons sharp
node build_deck.js 採用内製化_要点まとめ.pptx
```
