# AI採用アドバンス講座 ｜ 求めるケアスタッフを集める「0円採用」の設計図

介護・福祉事業向けの自社採用内製化プログラムを、講座教材として全 19 ページに詳細化した
スライド資料です。元となった「介護・福祉事業における自社採用戦略提案書」の内容を、AI 活用の観点を加えた
モジュール構成に組み直した、介護・福祉事業者向けの汎用教材です（特定企業向けの提案書では
ありません）。

## 元資料からの拡張点

提案書の 5 章立てを 6 モジュールの講座構成に組み直し、以下を追加しています。

- **MODULE 0（現状把握）** — 採用単価の算出ワークと定着率の確認。提案書には無かった、
  改善効果を測るための基準づくり
- **ワーク化** — ファネル分析、ペルソナ設計、ボトルネック診断を、その場で手を動かせる
  シート形式に変換
- **AI 活用レイヤー** — 各段階で AI に任せる作業／人がやる判断の切り分け、プロンプトの
  5 要素テンプレート（記入例つき）、工程別の所要時間比較
- **実行の具体化** — 職場体験会の時間配分と当日の禁止事項、スタッフ動画の質問 5 例、
  週次 15 分ミーティングの進行手順、90 日ロードマップ

## 出典と、AI 講座パートの扱い

19 ページ目に出典表を入れ、各ページがどの情報にもとづくかを 4 区分で明示しています。
AI 講座パートに該当するページ（P3・7・12・15・17）には、スライド右上に「AI 講座パート」の
バッジを表示しています。

| 区分 | 該当ページ | 出どころ |
|---|---|---|
| 提案書の内容を反映 | P4・6・9・11・14 | `source_recruitment_proposal.pdf` |
| 提案書の方針を実務手順に展開 | P2・5・8・10・13・16・18 | 本資料で独自に作成 |
| AI 講座パート | P3・7・12・15・17 | 本資料で独自に構成（下記参照） |
| 金額・比率・目安 | P2・5・10・16 | 業界一般の相場からの試算例 |

**「AI採用アドバンス講座」の公式教材テキストは提供を受けていません。** AI 講座パートは
生成 AI 活用の一般的な実務にもとづき、本資料の枠組みに合わせて独自に構成したもので、
特定の講座の内容を引用したものではありません。この旨は 19 ページ目にも明記しています。
実際の講座テキストが提供され次第、該当ページを公式内容に差し替えられます。

なお、元のウェビナー（utlink.jp）および Canva 資料は、作成環境のネットワーク制限により
直接参照できていません。

## 配色

配色は `brand-guidelines`（Anthropic ブランドガイドライン）のパレットに準拠しています。

| 用途 | 色 |
|---|---|
| 見出し・ダークスライド・表ヘッダー | Dark `#141413` |
| 明るい背景 | Light `#faf9f5` |
| 罫線・区切り | Light Gray `#e8e6dc` |
| 影・補助罫 | Mid Gray `#b0aea5` |
| 主アクセント（強調・数値） | Orange `#d97757` |
| 副アクセント（ファネル・グラフ） | Blue `#6a9bcc` |
| AI 講座パートの識別色 | Green `#788c5d` |

濃淡が必要な箇所（ファネルの 4 段階、ダークスライドの奥行き、本文の可読性）は、
上記 7 色から派生させたシェード／ティントを使用しています。

書体はブランド指定が Poppins / Lora ですが、いずれも日本語グリフを持たないため、
本資料は日本語表示用に Meiryo を使用しています。

## 数字の扱いについて

金額・比率はすべて業界一般の相場からの **試算例** で、資料上でもその旨を明記しています
（紹介手数料は年収の 20〜30%、介護職の年収 300〜400 万円クラスを前提）。実データに
差し替える場合は `build_deck.js` の該当スライドの `values` を編集してください。

「0円採用」は掲載料が 0 円という意味であり、求人票の作成・撮影・応募対応にかかる自社工数は
別途必要である点を、9 ページ目に注記しています。
